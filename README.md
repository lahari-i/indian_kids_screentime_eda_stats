# 📊 Project Title

Screen Time Analysis of Indian Children

---

## 🧾 Brief One-Line Summary

Analysis of screen time patterns among Indian children to understand usage behavior, health impacts, and differences across age, gender, device type, and location.

---

## 📖 Overview

This project explores screen time behavior among Indian children aged 8–18 years using real-world inspired data. It focuses on understanding how screen usage varies across different groups and whether it is associated with health impacts such as poor sleep, anxiety, and eye strain.

The project includes data cleaning, exploratory data analysis (EDA), visualization, and statistical hypothesis testing.

---

## ❗ Problem Statement

- Does screen time vary across age groups?
- Is screen time linked to health issues?
- Do different devices influence screen usage?
- Is there any difference between urban and rural children?
- How strong are these relationships statistically and practically?

---

## 📂 Dataset

- Source: Kaggle
- Name: Indian Kids Screen Time 2025
- Size: 9,712 records
- Features:
  - Age, Gender
  - Average Daily Screen Time
  - Primary Device
  - Educational vs Recreational Ratio
  - Health Impacts
  - Urban/Rural Location
  - Exceeding Recommended Limits

---

## 🛠 Tools and Technologies

- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- SciPy (Statistical Testing)
- Google Colab

---

## 🔬 Methods

- Data cleaning and preprocessing
- Handling missing values
- Feature engineering (health impact encoding)
- Exploratory Data Analysis (EDA)
- Data visualization (univariate, bivariate, multivariate)
- Hypothesis testing (t-test, chi-square test)
- Effect size calculation (Cohen’s d, Cramér’s V)
- Correlation analysis

---

## 📊 Key Insights

- Screen time is consistently high across all groups, averaging around 4–5 hours per day
- Age has a statistically significant but very weak relationship with screen time
- Poor sleep shows the strongest association with higher screen time
- Device type does not significantly influence screen usage patterns
- Urban and rural children show nearly identical screen time behavior
- Most relationships are statistically significant but practically weak
- Screen time appears to be a widespread behavior rather than group-specific

## 📌 Results & Conclusion

- Screen time among children is consistently high, averaging around 4–5 hours per day
- Most demographic factors such as age, gender, device type, and location show very weak influence on screen usage
- Poor sleep shows the strongest association with higher screen time among all health impacts
- Statistical tests show significant relationships, but effect sizes are generally small
- Overall, screen time appears to be a widespread behavior rather than strongly driven by specific groups or factors
